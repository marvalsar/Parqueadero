# Autos Colombia

## Descripción

Propuesta para el desarrollo de un software a la medida para el parqueadero colombiano **Autos Colombia**, con el propósito de facilitar y optimizar la gestión de sus operaciones diarias.

El sistema contempla dos perfiles de usuario: administrador y empleado en turno, con funcionalidades correspondientes a sus roles. Además, considera medidas de seguridad y diferentes situaciones que pueden presentarse durante el funcionamiento del parqueadero.

## Objetivo

Contribuir a la organización de la información, mejorar la gestión de las operaciones y favorecer un funcionamiento más seguro y eficiente.
